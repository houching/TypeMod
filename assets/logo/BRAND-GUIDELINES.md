# TypeMod — Brand & Logo Guidelines

**Concept:** **C2 — Modular T-Frame**  
Three modular blocks inside a soft-cornered square form an implied `T` with a negative-space metric channel — representing modular typography, system font replacement, and Latin + Khmer glyph merging.

---

## 1. Master Files (`assets/logo/`)

| Asset | Purpose |
|---|---|
| `typemod-symbol.svg` | Primary 2-colour symbol (light surfaces) |
| `typemod-symbol-dark.svg` | Primary 2-colour symbol (dark Vantage surfaces) |
| `typemod-symbol-small.svg` | Optical small-size cut (`16–24 px`, widened `38 px` channels) |
| `typemod-horizontal.svg` / `-dark.svg` | Primary horizontal lockup (100% outlined paths, zero `<text>`) |
| `typemod-stacked.svg` / `-dark.svg` | Stacked lockup for README hero, installer, and square badges |
| `typemod-wordmark.svg` | Standalone outlined `TYPEMOD` wordmark |
| `variants/` | Black, white, mono (`#4C77F7`), square, favicon, app-icon SVGs + PNGs + web icon set |
| `../logo.ico` | Multi-size Windows icon (`16×16`, `32×32`, `48×48`) built from the small-size cut |

---

## 2. Colour Palette (Aligned with Vantage Graphite)

| Role | Name | HEX | RGB |
|---|---|---|---|
| Primary Accent (`MOD` block) | Vantage Cobalt | `#4C77F7` | `76, 119, 247` |
| Light-Mode Ink (`TYPE` frame) | Vantage Graphite Ink | `#15181D` | `21, 24, 29` |
| Dark-Mode Ink (`TYPE` frame) | Vantage Off-White | `#EDEEF0` | `237, 238, 240` |
| One-Colour | Pure Black / Pure White | `#000000` / `#FFFFFF` | `0,0,0` / `255,255,255` |

- Use **2-colour** (`#15181D` + `#4C77F7` on light, `#EDEEF0` + `#4C77F7` on dark) as the primary mark.
- Use **1-colour** (`black`, `white`, or `mono-4c77f7`) when printing, embossing, or placing over busy imagery.

---

## 3. Clear Space & Minimum Size

- **Clear space:** Maintain at least **`0.25×` symbol width** (`64` units on the `256` grid) on all four sides of the symbol or lockup.
- **Minimum size:**
  - Symbol (standard): `24 px` digital / `8 mm` print.
  - Symbol (small-size cut / `.ico`): `16 px` digital.
  - Horizontal lockup: `120 px` wide minimum.

---

## 4. Misuse (Do Not)

- Do not stretch, skew, or rotate the mark.
- Do not close or narrow the negative-space `T` channels below the small-size cut.
- Do not apply drop shadows, outer glows, or unapproved gradients.
- Do not place the light-mode `#15181D` frame on a dark `#0D0F12` background (use `-dark.svg` instead).
